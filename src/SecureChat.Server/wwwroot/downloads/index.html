发布方法

你本地先生成安装包，再把它同步到服务端站点目录。之后公开服务端地址即可对外下载。

  1. 先运行安装包构建脚本，生成最新的桌面安装包。
  2. 再运行发布脚本，把安装包复制到 src/SecureChat.Server/wwwroot/downloads。
  3. 启动服务端后，访问 /downloads/ 检查页面和下载链接。
  4. 如果你已经配置 Cloudflare Tunnel 或公网入口，把这个下载页地址发给别人即可。
